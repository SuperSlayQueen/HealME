# HEALME MCP AI Tester

MCP-сервер для подключения HEALME к AI-клиенту. Он использует Playwright для запуска
приложения в настоящем браузере и умеет две вещи: проверять сайт (диагностика) и
совершать бронирование слотов у психологов через реальный интерфейс приложения.

Данные бронирований хранятся в IndexedDB браузера (база `healme`), поэтому записи
сохраняются между вызовами инструментов — используется постоянный профиль Playwright
в папке `mcp/.profile`.

## Инструменты

### Диагностика

- `smoke_test` — открывает HEALME и собирает HTTP-статус, console/page errors, ссылки и наличие воркеров.
- `check_workers` — отдельно проверяет ServiceWorker и SharedWorker.
- `ai_test` — браузерная проверка + передача отчёта нейросети (нужен `OPENAI_API_KEY`).

### Бронирование

- `list_psychologists` — список психологов: id, имя, специализация, цена, формат, рейтинг.
- `get_free_slots` — свободные слоты психолога на ближайшие 14 дней (кликами по реальному экрану выбора времени).
- `book_slot` — бронирует слот через настоящий интерфейс: выбор дня и времени, заполнение формы,
  согласие на обработку данных, подтверждение. Параметры:
  - `psychologist` (обязательно) — id или имя, например `maria` или «Мария Лебедева»;
  - `name`, `email` (обязательно) — данные клиента (валидируются как в форме);
  - `day` (YYYY-MM-DD) и `time` (ЧЧ:ММ) — необязательны: без них берутся ближайший день и первый свободный слот;
  - `comment` — необязательный комментарий.
  - При автоподборе день/время пропускают слоты, уже занятые другими записями профиля.
- `list_bookings` — все записи из IndexedDB: психолог, дата, время, статус, отзыв.

## Запуск HEALME

В корне проекта:

```bash
python server.py
```

Сайт будет доступен на `http://127.0.0.1:5500/`.

## Установка MCP

Перейдите в папку `mcp`:

```bash
npm install
npx playwright install chromium
```

Проверка без MCP-клиента (smoke-тест, e2e-бронирование, интеграционный тест сервера по stdio):

```bash
npm test
```

## Быстрая бронь из командной строки

Без MCP-клиента можно забронировать слот одним скриптом (использует те же инструменты,
что и MCP-сервер):

```bash
npm run book -- --psy maria --name "Анна Смирнова" --email anna@mail.ru
```

День (`--day YYYY-MM-DD`) и время (`--time ЧЧ:ММ`) необязательны — без них подберутся
ближайший день и первый свободный слот. Психолога можно задавать id или именем:
`--psy "Игорь Соколов"`.

## Показ сайта с данными MCP

```bash
npm run show
```

Открывает HEALME в **видимом окне браузера** с профилем MCP (`mcp/.profile`) —
с той же базой IndexedDB, с которой работает MCP. Брони, созданные через
`book_slot` или `npm run book`, видны в «Моих записях». Запускайте между
вызовами инструментов MCP: пока выполняется вызов, профиль занят.

## Демонстрация преподавателю (~5 минут)

Подготовка: `python server.py` в корне проекта, затем открыть эту папку
в AI-клиенте с подключённым MCP (конфиг ZCode лежит в `.zcode/config.json`).

1. **Сайт работает сам по себе**: главная → каталог → карточка психолога →
   выбор времени. Показать обычную запись руками (2 клика) и что время занято.
2. **MCP подключён**: спросить у AI-клиента «какие психологи есть в HEALME?» —
   вызовется `list_psychologists`.
3. «Покажи свободные слоты у Игоря» — `get_free_slots`.
4. «Забронируй у Игоря Соколова на ближайшую дату на 14:00, имя Иван Демов,
   email ivan@mail.ru» — `book_slot` пройдёт реальный интерфейс записи.
5. «Покажи все мои записи» — `list_bookings` покажет новую бронь из IndexedDB.
6. `npm run show` — видимое окно: та же бронь в «Моих записях» на сайте.
7. `npm test` — smoke, e2e-бронирование и stdio-тест MCP-сервера, всё PASS.
8. Если спросят «где тут MCP»: `mcp/server.js` (регистрация инструментов),
   `mcp/tools.js` (реализация), `.zcode/config.json` (подключение к клиенту).

Если AI-клиента под рукой нет — весь сценарий брони показывает `npm run book`
(способ 1), а корректность MCP-сервера — `node tests/mcp.js`, который общается
с сервером по stdio как настоящий клиент.

## AI-проверка

Для нейросетевого анализа задайте API-ключ:

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="ваш_ключ"
$env:OPENAI_MODEL="gpt-5-mini"
```

После этого MCP-клиент может вызвать инструмент `ai_test`.

Важно: API-ключ не хранится в проекте и не добавлен в репозиторий.

## Подключение к MCP-клиенту

Пример конфигурации для MCP-клиента:

```json
{
  "mcpServers": {
    "healme-ai-tester": {
      "command": "node",
      "args": ["C:/путь/к/HealME/mcp/server.js"],
      "env": {
        "HEALME_URL": "http://127.0.0.1:5500/"
      }
    }
  }
}
```

Путь нужно заменить на фактический путь к проекту.

## Хранилище данных

Приложение HEALME хранит записи в **IndexedDB** (база `healme`, хранилище `kv`).
MCP-сервер работает с тем же браузером и профилем, поэтому:

- брони, сделанные через `book_slot`, видны в интерфейсе HEALME («Мои записи»);
- `list_bookings` читает ту же самую базу;
- папка `.profile` игнорируется git — это просто кэш браузера.

## Что добавлено в сам HEALME

### IndexedDB

`js/db.js` — хранилище на IndexedDB с кэшем в памяти для синхронного рендера.
При первом запуске старые данные переносятся из localStorage. Синхронизация вкладок —
через SharedWorker (запасной канал — BroadcastChannel).

### SharedWorker

`js/shared-worker.js` синхронизирует записи между открытыми вкладками. Изменение записи в одной вкладке передаётся другим вкладкам.

### ServiceWorker

`sw.js` кэширует оболочку приложения и основные ресурсы. После первого запуска приложение может открываться из кэша без сети.

ServiceWorker, SharedWorker и IndexedDB работают в браузере через HTTP(S), поэтому для проверки используйте `python server.py` или Live Server. Открытие `index.html` двойным кликом не подходит.
