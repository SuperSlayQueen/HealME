# HEALME — сервис записи к психологам (демо на JavaScript)

Без сборки и зависимостей: чистые HTML, CSS и JS. Данные хранятся в `localStorage`.

## Запуск
Откройте `index.html` двойным щелчком или запустите Live Server в VS Code. Для публикации подойдёт GitHub Pages.

## Структура
- `index.html` — оболочка приложения
- `css/styles.css` — стили (цвета взяты из макетов Figma: `#FAF9FF`, `#F1F3FF`, `#963AFF`, `#C2F439`, `#1D2840`)
- `js/data.js` — психологи, отзывы, время приёма (вымышленные данные)
- `js/app.js` — маршрутизация по `#`, все экраны и действия
- `assets/` — логотип и фото из макетов

## Экраны (маршруты)
| Маршрут | Экран |
|---|---|
| `#/` | Главная |
| `#/psychologists` | Каталог с фильтрами (запрос, формат, цена, время), состояния «загрузка», «пусто», «ошибка» (`#/psychologists?fail`) |
| `#/psychologist/maria` | Карточка психолога |
| `#/time/maria` | Выбор времени (с параметром `?r=<id>` — перенос записи) |
| `#/form/maria` | Форма записи с проверкой полей |
| `#/done/ok`, `moved`, `cancelled`, `review`, `report`, `wait` | Экраны результата |
| `#/my`, `#/my?t=past` | Мои записи |
| `#/my/<id>` | Детали записи, отмена и перенос (не позднее чем за 24 часа) |
| `#/review/<id>`, `#/report/<id>` | Отзыв и сообщение о проблеме |
| `#/help` | Срочная помощь |

## Что умеет
- Запись: выбор дня и времени, проверка имени и email, согласие на обработку данных, защита от занятого времени.
- Файл календаря `.ics` с нейтральным названием «Встреча».
- Отмена и перенос (один раз, не позднее чем за 24 часа), отзыв после встречи, жалоба при низкой оценке.
- Кнопка «Удалить мои данные» стирает записи с устройства.
- В первый запуск создаётся демо-запись в прошлом, чтобы можно было попробовать отзыв.

## Что можно доработать
Настоящий бэкенд, вход по паролю, отдельный экран листа ожидания, ещё психологи (для каждого нужно фото в `assets/` и запись в `js/data.js`).


## Новые технологии

- `js/shared-worker.js` — SharedWorker для синхронизации состояния записей между вкладками.
- `sw.js` — ServiceWorker для кэширования оболочки приложения и работы без сети.
- `mcp/` — MCP-сервер для браузерного и AI-тестирования HEALME через Playwright.

### Быстрая проверка

1. Запустить сайт через HTTP, например `python -m http.server 5500`.
2. Открыть `http://127.0.0.1:5500/`.
3. Для MCP перейти в `mcp`, выполнить `npm install` и `npx playwright install chromium`.
4. Выполнить `npm test`.
5. Для AI-проверки задать `OPENAI_API_KEY` и подключить `mcp/server.js` к MCP-клиенту.

Подробности находятся в `mcp/README.md`.
